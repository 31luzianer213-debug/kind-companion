# Memória do projeto

- O painel `/painel` usa uma hierarquia visual compacta: ações principais no cabeçalho, indicadores financeiros, pendências, análise e histórico.
- A paleta escura prioriza fundo azul-marinho, superfícies discretas, índigo como ação principal e verde/âmbar/rosa apenas para estados.
- A tipografia permanece Plus Jakarta Sans na interface e JetBrains Mono somente para dados técnicos.
