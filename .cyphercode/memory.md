# Memória do projeto

- O painel `/painel` usa uma hierarquia visual compacta: ações principais no cabeçalho, indicadores financeiros, pendências, análise e histórico.
- A identidade visual global prioriza fundo azul-marinho, superfícies discretas, índigo como ação principal e verde/âmbar/rosa somente para estados.
- As páginas devem usar menos sombras, bordas mais suaves, espaçamento generoso e cartões apenas para agrupar informações relacionadas.
- A tipografia permanece Plus Jakarta Sans na interface e JetBrains Mono somente para dados técnicos.
- Reformulações visuais preservam textos, ações, integrações, regras de negócio e comportamento responsivo existentes.
