# Memória do projeto

- A identidade visual global usa fundo azul-marinho, superfícies discretas, índigo como ação principal e verde/âmbar/rosa somente para estados.
- As páginas priorizam hierarquia visual clara: cabeçalho objetivo, ações principais destacadas, indicadores compactos, pendências antes de histórico e cartões apenas para agrupar informações relacionadas.
- A navegação autenticada usa sidebar limpa, grupos bem separados, estados ativos em índigo e badges apenas quando indicam uma pendência real.
- A autenticação usa uma composição dividida em desktop: apresentação da plataforma à esquerda e formulário focado à direita; no mobile, o formulário ocupa toda a tela.
- A tipografia permanece Plus Jakarta Sans na interface e JetBrains Mono somente para dados técnicos.
- As reformulações visuais preservam textos, ações, integrações, regras de negócio, fluxos de autenticação, responsividade e acessibilidade existentes.
- As páginas usam bordas suaves, sombras discretas, espaços em branco maiores e estados de cor semânticos para reduzir a poluição visual.
